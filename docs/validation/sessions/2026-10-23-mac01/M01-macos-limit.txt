Profil danach wieder 75–80 %.

== Nebenbefund LED (behoben) ==
Vorher: "setMagSafeLED(auto) => failed" 9718-mal im Log; Schreibversuch in jedem Regeltakt.
Messung ACLC als root (writeKey jeweils true):
  write 0: sofort 4, +0.3 s 4, +1.3 s 3   (0 liest sich nie als 0, sondern als Firmware-Farbe)
  write 3: sofort 3, +0.3 s 3, +1.3 s 3
  write 4: sofort 3, +0.3 s 4, +1.3 s 4   (Readback um ~0.3 s verzögert)
  write 1: sofort 4, +0.3 s 1, +1.3 s 1   (LED aus funktioniert)
Fix: .auto vertraut dem Schreibergebnis, Farben warten bis 0.7 s auf den Readback, fehlgeschlagene Ziele
werden nicht in jedem Takt wiederholt. Danach: "setMagSafeLED(green) => ok", 0 Fehlschläge in 70 s, ACLC = 03.
