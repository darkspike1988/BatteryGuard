# B-Guard 0.3.4 — Dein Symbolstil

- Monochromer Ladering, Batterie oder Schild als Menüleistensymbol.
- Darstellung mit einem Klick zurücksetzen; Ladeprofil und andere Einstellungen bleiben erhalten.
- Netzteilanschluss wird nicht mehr pauschal als laufende Akkuladung dargestellt; tatsächliches Laden, Entladen und fehlende Steuerung werden unterschieden.
